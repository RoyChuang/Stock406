# Stock406 盤勢儀表板

00406A、台股加權、台積電、S&P 500、Nasdaq、費半、VIX 的技術指標儀表板，包含 MACD、KD、RSI、均線和布林通道，以及部位損益與分批加碼試算。

- 線上版：https://roychuang.github.io/Stock406/（GitHub Actions 每 15 分鐘抓一次 Yahoo Finance 資料）
- 本機即時版：`node server.js`，然後打開 http://localhost:4060

部位資料只存在瀏覽器的 localStorage，不會上傳。本專案僅供技術指標計算與一般資訊參考，不構成投資建議。
